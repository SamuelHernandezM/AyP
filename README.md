# AyP
Proyecto de Programacion 

Instrucciones del Proyecto: 
El equipo deberá crear un programa que incluya un menú principal con las siguientes 
opciones: 
1. Registrar alumnos (al menos 4 alumnos o más) 
o Nombre completo 
o Matrícula 
o Carrera o programa académico 
o Edad 
o Validar que la matrícula no esté repetida 
2. Registrar calificaciones 
o Capturar las calificaciones de tres a cinco materias (el equipo decide 
cuántas) 
o Validar entradas (solo números entre 0–100) 
o Guardar el promedio general del alumno 
3. Dar de baja a un alumno del sistema 
o Eliminación por número de matrícula (Ustedes deciden si es int o string) 
o Mostrar mensaje de confirmación (de eliminación y posteriormente 
regresar al menú) 
4. Mostrar la boleta o ficha académica del alumno 
Debe incluir: 
o Nombre 
o Matrícula 
o Carrera 
o Calificaciones por materia 
o Promedio general 
o Estatus académico (Aprobado / Reprobado) 
5. Mostrar estadísticas del grupo 
El sistema deberá calcular:
o Número total de alumnos registrados 
o Número de alumnos aprobados (promedio ≥ 70) y quienes fueron 
(nombre). 
o Número de alumnos reprobados (promedio < 70) y quienes fueron 
(nombre). 
o Promedio general del grupo 
o Alumno con mejor promedio 
o Alumno con peor promedio 

1. Entrega del Código Fuente 
El equipo deberá subir un archivo comprimido (.zip o .rar) que incluya: 
a) Código fuente completo del proyecto (archivos.cpp) 
• El código debe estar ordenado, indentado y comentado adecuadamente. 
• Cada función debe contar con un comentario breve que explique su 
propósito. 
• El menú y las opciones deben estar claramente implementadas. 
b) Carpeta con capturas de pantalla 
Debe contener evidencia visual de: 
• Ejecución del menú principal 
• Carga de datos (registro de elementos) 
• Eliminación de registros 
• Búsqueda o consulta de información 
• Estadísticas o reportes 
• Mensajes de error por entradas no válidas (si los hay) 
2. Reporte final del proyecto (PDF) 
El equipo deberá presentar un documento FORMAL en PDF que incluya: 
Carátula 
• Logo de la escuela 
• Título del proyecto 
• Nombre de los integrantes del equipo 
• Materia 
• Maestro 
• Carrera 
• Fecha 
Introducción 
Breve descripción del sistema desarrollado, su propósito y su utilidad. 
Herramientas utilizadas en el proyecto 
Describir todas las herramientas utilizadas en el proyecto, aplicaciones, librerías, bibliotecas 
y una breve descripción de su funcionamiento. Por ejemplo, Dev C++, Visual Studio Code, 
“iostream”, “system”, etc. 
Descripción del funcionamiento del programa 
Debe incluir: 
• Explicación del menú principal 
• Explicación de cada opción del menú 
• Breve justificación de la estructura de datos utilizada 
• Diagrama sencillo del proceso (puede ser diagrama de flujo general, mapa de 
proceso o pseudocódigo del menú) 
Ejemplos de ejecución 
• Capturas de pantalla organizadas y con título (ej. “Figura 1: Registro de 
producto”) 
• Descripciones breves debajo de cada captura 
Conclusión 
Reflexión del equipo sobre: 
• Dificultades encontradas 
• Aprendizajes obtenidos 
• Aspectos que podrían mejorarse 
Anexos (opcional) 
• Cualquier evidencia adicional que el equipo considere relevante
3. Nomenclatura del archivo 
El archivo ZIP deberá nombrarse de la siguiente manera: 
• PF_Equipo#_Carrera.zip 
El PDF se deberá nombrar: 
• PF_Reporte_Equipo#_Carrera.pdf 
4. Modo de entrega 
El equipo deberá subir ambos archivos (ZIP + PDF) en la sección correspondiente del 
Brightspace (BS) antes de la fecha límite marcada en la plataforma. 
No se aceptarán entregas por correo, USB o mensajería personal. 
5. Criterios de evaluación 
• Funcionamiento correcto del sistema 
• Complejidad adecuada del menú y sus opciones 
• Validación de datos de entrada 
• Calidad del código (orden, indentación, comentarios) 
• Corrección lógica en cada función 
• Evidencias de ejecución 
• Presentación del reporte final 
• Trabajo colaborativo
